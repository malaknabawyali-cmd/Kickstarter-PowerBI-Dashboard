🎯 Kickstarter Crowdfunding Projects Analysis — Power BI
PROJECT OVERVIEW
An interactive Power BI dashboard analyzing more than 700,000 Kickstarter projects to explore funding trends, project success rates, and regional distributions.
TOOLS AND TECHNOLOGIES
• Power BI Desktop
• Power Query (M) for data transformation and ETL
• DAX for custom measures and aggregations
• Data modeling with hierarchies and relationships  
KEY MEASURES
• Projects — Total number of projects
• Number of Backers — Total backer engagement
• Total Pledged — Total funding raised in dollars
• Total Goal — Combined funding goals in dollars  
KEY INSIGHTS
1. Projects raised more than $6.48 billion across 702,000+ campaigns.
2. Technology and Design projects had the highest individual funding goals.
3. The dashboard makes it easy to explore project outcomes and compare successful and failed campaigns.
